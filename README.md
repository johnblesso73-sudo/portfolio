# John Blesso J J — 3D Canvas Scroll Portfolio

A modern, high-performance personal portfolio featuring an interactive 240-frame 3D canvas scroll animation, smooth native scroll synchronization, and transparent glassmorphic UI components.

## 🚀 Live Demo & Local Run
To run the project locally with high-performance frame caching:
```bash
node server.js
```
Then visit `http://localhost:3000/` in your browser.

## 🛠️ Tech Stack
- **Frontend**: Vanilla HTML5, High-DPI HTML5 Canvas Engine, Modern CSS3
- **Local Server**: Node.js HTTP Server with long-term cache headers for PNG frame sequence
- **Scroll Engine**: Native scroll synchronized with `requestAnimationFrame` lerp interpolation
